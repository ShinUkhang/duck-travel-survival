# 🦆 오리 서바이벌 월드투어

여행지를 선택하는 통합 서바이벌 게임!

https://shinukhang.github.io/duck-travel-survival/

## 여행지

| 여행지 | 파일 | 설명 |
|--------|------|------|
| 🦆 기본오리 | `duck.html` | 클래식 좀비 오리 아레나 서바이벌 |
| 🗾 후쿠오카 | `fukuoka.html` | 후쿠오카 명소 10곳, 신칸센, 타임어택 |
| 🏙️ 대구 | `daegu.html` | 대구 명소 12곳, 팔공산, 7종 무기 |

## 구조

- `index.html` — 여행지 선택 허브 (목적지 선택 화면)
- 각 여행지는 독립된 단일 HTML 파일로 동작

## 플레이 방법

1. 여행지 카드를 탭
2. 가로 모드 권장 🔄
3. WASD/방향키 또는 터치 조이스틱으로 이동 (자동 공격)

## 아이폰 전체화면 안내

아이폰 Safari는 전체화면 API를 지원하지 않습니다.
홈 화면에 추가(공유 → 홈 화면에 추가)하면 앱처럼 전체화면으로 실행됩니다.
